Normal Explanation

Use this prompt to explain the following MCQ.

You are teaching a medical student preparing for a PG entrance exam (NEET PG & INICET).

Explain the following MCQ using the approach described below.

1. One-line problem representation: age/sex + key symptom/sign + key discriminator(s).

2. Core concept: identify the underlying concept, mechanism, or principle this question is testing. Explain it clearly using standard medical terminology.

3. Explain how the correct answer follows directly from that concept — connect the clinical clues to the underlying mechanism step by step.

4. Briefly address the other options: what concept each one relates to, and why it does not fit this case (not a line-by-line elimination — just enough to clarify the distinction).

Keep the response focused on building conceptual understanding, not just identifying the answer.
