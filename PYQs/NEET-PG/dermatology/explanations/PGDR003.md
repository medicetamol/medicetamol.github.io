# Continue ALT and Start Steroids

**Type 1 (reversal) lepra reaction** is a delayed hypersensitivity flare in borderline leprosy that inflames existing lesions and causes **neuritis**. Start **prednisolone** (about 40 mg/day, tapered over months; doses vary by guideline) to prevent permanent nerve damage, and **continue multidrug therapy**.

## Trigger Point

> **Inflammation of pre-existing lesions** with **nerve involvement** while on MBMDT.

## Lepra Reactions

| Feature | Type 1 (reversal) | Type 2 (ENL) |
|---|---|---|
| Mechanism | Type IV (cell-mediated) | Type III (immune complex) |
| Seen in | Borderline leprosy | LL and BL |
| Picture | Inflamed existing patches, neuritis | New tender nodules, fever, neuritis |
| Treatment | Prednisolone | Prednisolone, thalidomide, clofazimine |

## Why Not the Other Options?

**A. Stop ALT and start steroids**
A reaction is not drug failure. Stopping anti-leprosy treatment is wrong.

**B. Stop ALT and start thalidomide**
Thalidomide treats type 2 reaction (ENL), not type 1, and is teratogenic.

**D. Continue ALT and give thalidomide**
The right instinct to continue ALT, but thalidomide is ineffective in type 1 reaction.

## Mind Capsule

> Lepra reaction = never stop MDT.
> Type 1 with nerve involvement = steroids; type 2 = steroids, thalidomide or clofazimine.
