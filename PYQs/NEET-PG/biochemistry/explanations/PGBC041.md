# Multiplex PCR

**Multiplex PCR** uses **several primer pairs in one reaction** to amplify multiple targets at the same time. It is ideal for **syndromic panels** (e.g. meningitis, where bacteria, viruses and fungi can all cause the same picture), as in the FilmArray meningitis/encephalitis panel.

## Trigger Point

> **Syndromic illness like meningitis** = many possible pathogens in one sample.

## Types of PCR

| Type | Use |
|---|---|
| Multiplex | Many targets in one reaction (syndromic panels) |
| Nested | Two rounds of primers to increase sensitivity and specificity |
| Real-time (qPCR) | Quantification as amplification occurs |
| RT-PCR | RNA viruses, using reverse transcriptase |

## Why Not the Other Options?

**B. Uniplex PCR**
Amplifies a single target with one primer pair.
It would miss other pathogens causing the same syndrome.

**C. Attributed PCR**
This is not a standard PCR type.
It is a distractor.

**D. Nested PCR**
Uses two sets of primers in sequence to improve sensitivity for one target.
It does not screen multiple pathogens at once.

## Mind Capsule

> Syndromic panel = **multiplex PCR**; improved sensitivity for a single low-copy target = nested PCR.
