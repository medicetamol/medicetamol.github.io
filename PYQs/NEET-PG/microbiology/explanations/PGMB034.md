# Terminal Complement (C5-C9) Assay

Deficiency of the **terminal complement components (C5-C9, the membrane attack complex)** predisposes to **recurrent *Neisseria* infections** (meningococcal and gonococcal), since lysis of the gram-negative diplococci depends on the MAC.

## Trigger Point

> **Recurrent *Neisseria gonorrhoeae*** infections.

## Immunodeficiency and Tests

| Defect | Test |
|---|---|
| Terminal complement (C5-C9) | CH50, individual component assay |
| C1 esterase inhibitor | C4 level, C1-INH assay (hereditary angioedema) |
| Phagocyte oxidative burst (CGD) | NBT / DHR test |
| B-cell deficiency | Immunoglobulin levels |

## Why Not the Other Options?

**A. C1 esterase inhibitor assay**
Tests for hereditary angioedema, which presents with swelling episodes.
It does not cause recurrent *Neisseria* infection.

**B. Quantitative immunoglobulin levels**
Detect antibody deficiency, with recurrent sinopulmonary infections by encapsulated bacteria.
Not the best explanation for isolated *Neisseria*.

**C. Nitroblue tetrazolium test**
Used for **chronic granulomatous disease** with catalase-positive organisms (*S. aureus*, *Aspergillus*).
It does not explain *Neisseria*.

## Mind Capsule

> Recurrent **Neisseria** = **C5-C9 deficiency** (MAC); recurrent catalase-positive infections = CGD.
