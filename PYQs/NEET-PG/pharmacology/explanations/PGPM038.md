# Phase 3 (Repolarisation)

**Amiodarone** is a **class III antiarrhythmic** that mainly blocks **K⁺ channels** (IKr), **prolonging phase 3 repolarisation** and thus the action potential duration and effective refractory period. It also has class I, II and IV actions.

## Trigger Point

> **Primary site of action** of amiodarone on the action potential.

## Vaughan Williams Classes

| Class | Action | Phase affected |
|---|---|---|
| I | Na⁺ channel block | Phase 0 |
| II | β-blockers | Phase 4 |
| III | K⁺ channel block | **Phase 3** |
| IV | Ca²⁺ channel block | Phase 2 (and nodal phase 0) |

## Why Not the Other Options?

**A. Phase 0**
Rapid depolarisation is slowed by **class I** drugs (Na⁺ channel blockers).
This is a secondary action of amiodarone.

**B. Phase 2**
The plateau is influenced by calcium channel blockers (class IV).
It is not the primary site of amiodarone.

**D. Phase 4**
The resting phase is affected by β-blockers (slope in nodal cells).
It is not the primary action of amiodarone.

## Mind Capsule

> Class III (amiodarone, sotalol, ibutilide, dofetilide) = **K⁺ block, phase 3, ↑ APD and QT**.
