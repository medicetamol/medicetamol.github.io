# Start Noradrenaline

In **septic shock** where MAP stays below 65 mmHg despite adequate fluid (about 30 mL/kg crystalloid), the **first-line vasopressor is noradrenaline (norepinephrine)**.

## Trigger Point

> Septic shock with BP 58/30 mmHg and MAP 58 mmHg persisting after 3 L of crystalloid.

## Why Not the Other Options?

**A. Start dopamine**
An alternative only in selected patients with low risk of tachyarrhythmias and bradycardia, since it carries more arrhythmias.

**C. Repeat crystalloid fluid**
Adequate resuscitation has already been given, and further fluids risk overload.

**D. Start vasopressin**
Added as a second agent when noradrenaline alone is inadequate.

## Mind Capsule

> Septic shock not responding to fluids = noradrenaline first; add vasopressin if MAP is still low.
