# Stage 0

Adenocarcinoma confined to the **mucosa** (intramucosal carcinoma) has not breached the muscularis mucosae and is staged **Tis, N0, M0 = Stage 0**. Tumour size (6 cm here) does not change the T category.

## Colorectal Cancer Staging (AJCC)

| Stage | TNM |
|---|---|
| 0 | Tis N0 M0 |
| I | T1–T2, N0, M0 |
| II | T3–T4, N0, M0 |
| III | Any T, N1–N2, M0 |
| IV | Any T, any N, M1 |

## Trigger Point

> Adenocarcinoma limited to the mucosa, with no nodal or distant metastasis.

## Why Not the Other Options?

**B. Stage I**
Needs invasion into the submucosa (T1) or muscularis propria (T2).

**C. Stage II**
Needs invasion through the muscularis propria (T3) or beyond (T4), without nodes.

**D. Stage III**
Requires lymph node metastasis, which is absent.

## Mind Capsule

> Mucosa-limited carcinoma, N0 M0 = Tis = Stage 0, regardless of size.
