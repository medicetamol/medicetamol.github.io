# Staphylococcal Food Poisoning

A **point-source epidemic** follows a **single common exposure** at about the same time. Cases rise and fall steeply within **one incubation period**. **Staphylococcal food poisoning** has a **short incubation (1-6 hours, preformed enterotoxin)** with a narrow range, giving a sharp peak.

## Trigger Point

> All cases with symptoms within a **short interval**, incidence **peaking together**.

## Types of Epidemic Curve

| Type | Curve |
|---|---|
| Point source | Single sharp peak within one incubation period |
| Continuous common source | Prolonged plateau |
| Propagated | Successive waves at the serial interval |

## Why Not the Other Options?

**A. Salmonellosis**
Incubation is longer and more variable (6-72 hours), so the peak is broader.

**C. Measles**
Spreads person to person, giving a **propagated** curve with successive waves.

**D. Typhoid fever**
Incubation is 1-3 weeks and widely variable, so cases are spread out over time.

## Mind Capsule

> Sharp, narrow peak = **point-source** with a **short incubation**, as in **staphylococcal** food poisoning.
