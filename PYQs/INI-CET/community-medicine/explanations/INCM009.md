# PPV = 64.3%

**Positive predictive value** is the probability that a person with a positive test truly has the disease: **PPV = TP / (TP + FP)**. It depends on disease prevalence.

## Working

1. Test positives = TP + FP = 90 + 50 = 140
2. PPV = 90 / 140 = 0.643 = **64.3%**

## Trigger Point

> **90 true positives and 50 false positives**: only the positive-test row is needed.

## Why Not the Other Options?

**B. 90%**
This is the number of true positives, not a proportion of all positives.
It ignores the false positives.

**C. 50%**
This is the number of false positives.
It is not a predictive value.

**D. 35.7%**
This is 50/140, the proportion of positives that are false (1 - PPV).
It is the complement of the answer.

## Mind Capsule

> PPV = TP / (TP + FP): of all who test positive, how many truly have the disease.
